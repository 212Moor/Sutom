# SUTOM

Bienvenue sur la page du projet SUTOM, une réplique du célèbre jeu de devinette de mots, inspiré par Motus. Ce jeu a été conçu en Python et permet aux joueurs de deviner un mot inconnu à partir de plusieurs tentatives successives en recevant des indices sur la précision des lettres proposées.

Règles du Jeu:
Le jeu choisit un mot aléatoire que le joueur doit deviner.
Le joueur a six tentatives pour deviner le mot.
Chaque tentative doit être un mot valide de la même longueur que le mot à deviner.
Après chaque tentative, le jeu indique combien de lettres sont correctement placées et combien sont correctes mais mal placées.

Fonctionnalités:
Chargement des mots à partir d'un fichier CSV.
Indication du nombre de lettres correctement placées et mal placées.
Indice initial donné pour la première lettre du mot à deviner.
